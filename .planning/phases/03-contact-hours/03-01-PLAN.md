## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | Address.astro directions link (reverse tabnabbing) | mitigate | target="_blank" always paired with rel="noopener noreferrer"; asserted by verify script check (c) |
| T-03-02 | Tampering | tel:/mailto: href construction | mitigate | telHref strips everything but digits and leading +; mailtoHref/directionsUrl use encodeURIComponent; Astro escapes attribute values |
| T-03-03 | Information Disclosure | Third-party requests before consent | mitigate | No iframe, preconnect or script in this plan; directions is a plain link (D-03, D-09) |
| T-03-04 | Spoofing | Placeholder address/phone shipping to production | accept | Placeholder values are obviously fake; launch-time check is Phase 4 (LAUNCH-04) and v2 QUAL-V2-01 |
