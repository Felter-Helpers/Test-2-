# Phase 1 — Foundation & Home — UI Design Contract

> Visual and interaction contract for Foundation & Home page. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Upstream:** Decisions locked in 01-CONTEXT.md (D-01 through D-07, Claude's Discretion defaults). Design system established here reused by Phase 2, Phase 3, and Phase 4.

---

## Design System

| Property | Value | Source |
|----------|-------|--------|
| Tool | none | Astro + plain CSS, no component library |
| Preset | not applicable | No shadcn |
| Component library | none | Custom Astro components |
| Icon library | inline SVG | Phase 1 discretion, this spec |
| Font | System stack (San Francisco, Segoe UI, Roboto, sans-serif) | Phase 1 D-02, 01-CONTEXT.md |

**Rationale:** Astro ships zero JavaScript by default. All components are `.astro` files with scoped CSS. No third-party UI library; all components built custom. SVG icons are inlined in components (no external icon library).

---

## Spacing Scale

8-point scale. All values are multiples of 4 for alignment and mobile touch targets.

| Token | Value | CSS Variable | Usage |
|-------|-------|--------------|-------|
| xs | 4px | `--space-xs` | Icon gaps, inline padding, button borders |
| sm | 8px | `--space-sm` | Compact element spacing, form field gaps |
| md | 16px | `--space-md` | Default element spacing, section gutters, nav gaps |
| lg | 24px | `--space-lg` | Section padding, card margins |
| xl | 32px | `--space-xl` | Layout gaps, major component spacing |
| 2xl | 48px | `--space-2xl` | Major section breaks, hero-to-content gap |
| 3xl | 64px | `--space-3xl` | Page-level spacing, hero bottom, footer top |

**Location:** `src/styles/tokens.css` as CSS custom properties.

**Exceptions:** None at Phase 1. Phase 3 defines specific touch-target heights (44px minimum per WCAG 2.5.5 Level AAA) for buttons; Phase 1 respects this pattern.

## Typography

All font sizes in pixels; line heights as unitless ratios. Only two font weights used across the site: 400 (regular) and 600 (semibold). This matches Phase 3's expectations and minimizes web-font overhead.

**Font families (locked by Phase 1 D-02, 01-CONTEXT.md):**
- `--font-body`: System stack (San Francisco, Segoe UI, Roboto, sans-serif) — applied to body text and paragraphs
- `--font-heading`: System stack (same as body) — applied to headings

**Font sizes:**

| Role | Size | Weight | Line Height | CSS Variable | Usage |
|------|------|--------|-------------|--------------|-------|
| Small | 14px | 400 | 1.5 | `--text-small` | Helper text, captions, secondary copy, footer text |
| Body | 16px | 400 | 1.5 | `--text-body` | Paragraph text, descriptions, testimonials |
| Heading | 24px | 600 | 1.2 | `--text-heading` | Section headings, testimonials heading, card titles |
| Display | 32px | 600 | 1.2 | `--text-display` | Page heading (implicit), hero shop name |

**Location:** `src/styles/tokens.css`.

## Color

### Palette

Neutral and ready to brand: mostly greys and white with a single accent color (Phase 1 D-01). This design is intentionally generic so the client's brand colors can drop in through the token file without rework.

| Role | Hex Value | CSS Variable | Usage | Notes |
|------|-----------|--------------|-------|-------|
| Dominant (60%) | #FFFFFF | `--color-bg-primary` | Page background, large surfaces | Pure white; light alternative #F9F9F9 if too harsh. TBD at planning. |
| Secondary (30%) | #F5F5F5 | `--color-bg-secondary` | Card backgrounds, footer, nav background, accented sections | Light grey, ~15-20% darker than dominant. Used for visual separation. |
| Text (Primary) | #1A1A1A | `--color-text-primary` | Body text, headings, labels | Near-black. WCAG AA contrast on dominant (4.5:1). |
| Text (Secondary) | #666666 | `--color-text-secondary` | Helper text, captions, muted labels | Mid-grey. Reduced emphasis. |
| Accent (10%) | #0066CC | `--color-accent` | Links, primary CTA buttons, focus states, interactive elements | Blue. Brand color TBD; swap via token file at final branding. |
| Accent (Hover/Active) | #0052A3 | `--color-accent-dark` | Hover/active states on accent elements | 20% darker shade of accent (#0066CC). |
| Destructive | #D32F2F | `--color-destructive` | Error messages, form validation (Phase 3+) | Red. Not used in Phase 1, defined for consistency. |
| Success | #388E3C | `--color-success` | Success messages (Phase 3+) | Green. Not used in Phase 1, defined for consistency. |
| Border/Divider | #EEEEEE | `--color-border` | Dividers, subtle borders | Very light grey. Used for visual structure. |

**Location:** `src/styles/tokens.css`.

### Accent Reserved For

Phase 1 D-01: one accent color for specific interactive elements only.

- **Links:** All `<a>` tags (e.g., "See what we offer" in hero)
- **Primary CTA buttons:** "See what we offer" button, "Get in touch" button (in testimonials section or footer)
- **Focus states:** Keyboard focus outlines on links and future form inputs (Phase 3+)
- **NOT used for:** Backgrounds, decorative elements, or secondary navigation

## Component-Specific Contracts

### Page Layout Structure (Mobile-first)

**All screens (320px and wider):**

1. **Notice banner** (conditional): Sticky, full-width, secondary background, text-centered, small padding
2. **Header:** Sticky, full-width, secondary background, logo on left, nav menu on right (desktop) or hamburger (mobile)
3. **Hero section:** Full-width, dominant background, centered text, logo + shop name + description + today's hours + two CTA buttons
4. **Highlight links section:** Two cards or buttons, "See what we offer" and "Get in touch"
5. **Testimonials section:** 3 cards, stacked on mobile (320-767px), grid on tablet+ (≥768px)
6. **Footer:** Full-width, secondary background, shop info (name, address, phone, email), nav links, copyright

**On mobile (< 768px):**
- Single column layout
- Buttons full-width
- Testimonials: 1 per row, stack vertically
- Navigation: Hamburger menu, slide-in drawer (no JavaScript required, pure CSS or minimal JS)

**On tablet/desktop (≥ 768px):**
- Buttons inline or side-by-side
- Testimonials: 3-column grid
- Navigation: Visible horizontal menu

### Header Component (`Header.astro`)

**Structure:**
- Logo (left): SVG text wordmark, e.g., "K" or "Kelvin" in accent color
- Navigation menu (right, desktop) or hamburger (mobile)
- Sticky positioning (stays at top on scroll)
- Full-width, secondary background (#F5F5F5)

**Navigation items:**
- Home
- What We Offer
- About
- Contact & Hours

**Mobile menu (< 768px):**
- Hamburger button (3 horizontal lines, 20px, primary text color) with:
  - `aria-label="Open menu"` (toggling to "Close menu" when expanded)
  - `aria-expanded="false"` (toggling to "true" when menu is open)
  - `aria-controls="nav-menu"` (pointing to nav element ID)
- Slide-in drawer from left or dropdown menu (ID: `nav-menu`)
- Menu items stacked vertically, padding `md` (16px)
- Keyboard-usable: Tab through items, Enter to navigate
- Close button (X) or click outside to close

**Desktop menu (≥ 768px):**
- Items inline, spacing `md` (16px) between links
- Hover state: underline or slight color change
- Active state: bold or underline (current page)

**Accessibility:**
- `<nav>` semantic element (ID: `nav-menu`)
- Menu button has `aria-expanded` attribute
- Menu list has `role="list"`
- Links have `aria-current="page"` when active

### Footer Component (`Footer.astro`)

**Structure:**
- Full-width, secondary background (#F5F5F5)
- Content: Shop name, address, phone (clickable `tel:`), email (clickable `mailto:`), copyright text
- Padding: `lg` (24px) vertical, `lg` (24px) horizontal on mobile; `xl` (32px) on tablet+
- Text size: Small (14px / 400)

**Content:**
- Shop name (16px / 600)
- Address (14px / 400, multi-line if needed)
- Phone: "Call: [phone-number]" as `<a href="tel:...">` link (accent color)
- Email: "Email: [email]" as `<a href="mailto:...">` link (accent color)
- Copyright: "© 2026 [Shop Name]. All rights reserved." (optional, placeholder)
- Nav links (optional): Repeat of header nav, smaller size

**Accessibility:**
- Phone and email are actual `<a>` links (`tel:` and `mailto:` href), not buttons

### Hero Component (`Hero.astro`)

**Structure (top to bottom):**
1. Logo: SVG, centered, ~64px or 80px size, accent color
2. Shop name: Display role (32px / 600), centered, padding `lg` (24px) top, `md` (16px) bottom
3. Description: Body role (16px / 400), centered, padding `md` (16px) bottom
4. Today's hours: Body role (16px / 400), centered, small padding (4px or 8px) top, color: accent or primary text
5. CTA buttons: Two buttons, "See what we offer" and "Get in touch", stacked on mobile, inline on tablet+, spacing `md` (16px) between
6. Padding: `3xl` (64px) top and bottom, `lg` (24px) left/right

**Today's hours logic:**
- Computed client-side using JavaScript
- Data inputs: `hours.weekly` (array of day objects with open/close times), `hours.exceptions` (array of special dates), `hours.timeZone` (e.g., "America/New_York")
- Output: "Today's Hours: 9am–6pm" or "Closed today" or "9am–12pm, 2pm–6pm" (split hours)
- Fallback (no-JS): Display weekly hours table as static text

**Button styling:**
- Min height: 44px (WCAG 2.5.5 touch target)
- Padding: `sm` (8px) horizontal, ~12px vertical
- Background: Accent (#0066CC)
- Text: White, 16px / 600, center-aligned
- Hover: Darker accent (#0052A3)
- Border-radius: 4px
- Mobile: Full-width, gap `md` (16px) between if stacked
- Desktop: Auto-width, gap `md` (16px) between if side-by-side

### Notice Banner Component (`NoticeBanner.astro`)

**Conditional rendering:**
- Only rendered if `banner.active === true` in data file
- If `banner.active === false` or `banner` object missing, component renders nothing

**Structure:**
- Full-width, sticky top
- Secondary background (#F5F5F5) or slightly different color for distinction (e.g., #FFF3CD if warning, #E3F2FD if info)
- Text centered or left-aligned, small size (14px / 400)
- Padding: `md` (16px) vertical, `lg` (24px) horizontal
- Optional: "X" dismiss button (right-aligned), closes via localStorage or page session

**Copy pattern:**
- "Notice: [text from data.banner.text]"
- Example: "Notice: We're closed for inventory on Dec 26th"

**Data structure:**
```yaml

  active: false  # Toggle visibility
  text: "We're closed for inventory on Dec 26th"
  startDate: 2026-12-26
  endDate: 2026-12-26
  # startDate/endDate may be used for validation or future automation
```

**Structure:**

- Grid of testimonial cards: 1 column on mobile (< 768px), 3 columns on tablet+ (≥ 768px)
- Gap between cards: `md` (16px)
- Each card: Secondary background (#F5F5F5), padding `lg` (24px), border-radius 4px, subtle shadow (optional)

**Card content (top to bottom):**

2. Author name (16px / 600): "Jane Doe"

## Responsive Design

### Breakpoints

| Name | Width | Changes |
|------|-------|---------|
| **Mobile** | < 768px | Single column, full-width buttons, stacked testimonials, hamburger menu |
| **Tablet+** | ≥ 768px | Full menu visible, side-by-side buttons (if space), 3-column testimonial grid |

**No other breakpoints.** Design scales fluidly between mobile and tablet breakpoints using flexbox and percentage widths. Max-width constraint (optional, for readability): ~1200px on very wide screens, centered.

### Responsive Patterns

- **Buttons:** Full-width on mobile, auto-width on tablet+ (or constrained to max-width)
- **Text:** Single-column on mobile, no multi-column text blocks
- **Images:** Aspect-ratio-based sizing (4:3 for testimonial images if used), responsive width, lazy loading (Astro Image)
- **Spacing:** Adjusts based on screen size via media queries or CSS custom properties

## Accessibility Baseline

**Semantic HTML:** All components use proper semantic elements (`<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`, `<a>`, `<button>`).

**Color contrast:** All text meets WCAG AA (4.5:1) on backgrounds. Accent color (#0066CC) on white has >4.5:1 contrast.

**Touch targets:** Buttons and links have minimum 44px height (WCAG 2.5.5 Level AAA). Touch targets are never smaller than 44px × 44px.

**Keyboard navigation:** Menu is keyboard-usable (Tab through nav items, Enter to navigate). Focus states are visible (outline or underline).

**Alt text:** All images (logos, placeholders, product photos in Phase 2+) have descriptive alt text. No "image" or generic "photo" alt text.

**Form fields (Phase 3+):** Labelled with `<label>` elements linked via `for` attribute. Required fields marked with `required` attribute.

      status: "special"
      hours: { open: "11:00", close: "17:00" }

banner:
  active: false
  text: "We're closed for inventory on Dec 26th"
